# DROP.

Landing page de dropshipping de ropa de marca, en un solo archivo HTML autocontenido (sin dependencias externas — CSS, JS y todas las fotografías van incrustadas).

- **Diseño**: editorial oscuro con acento índigo, tipografía condensada estilo sello de etiqueta.
- **Intro animada**: secuencia de texto en negro con efecto de zoom hacia la página principal.
- **Parallax**: en el hero, secciones de contenido, tarjetas de producto y tiles de navegación.
- **Navegación por páginas**: menú "Productos" con filtros por categoría y género (Calzado, Pantalones, Playeras, Camisas, Hombres, Mujeres), cada uno con su propia página y transición parallax entre vistas.
- **Catálogo**: 8 productos con fotografía real (Unsplash, licencia libre), precio anterior/actual y descuento.

## Ver el sitio

Abre `index.html` directamente en el navegador, o publícalo con GitHub Pages (Settings → Pages → Deploy from branch → `main` / `/`).
